# 🏗️ Assistant BTP – AI Chatbot for Construction Professionals

AI assistant designed for construction and building professionals using Flowise and Gemini AI workflows.

---

# 🚀 Overview

Assistant BTP is a prototype AI assistant created to help construction and building professionals interact with an intelligent conversational system through a web interface.

This project combines:
- AI workflows
- conversational interfaces
- web integration
- deployment experimentation

The assistant was built using Flowise and connected to a frontend deployed on GitHub Pages.

The backend AI workflow is currently exposed using ngrok for rapid prototyping and testing purposes.

---

# 🧠 Features

✅ AI conversational assistant  
✅ Construction-oriented use cases  
✅ Flowise workflow integration  
✅ Web interface using HTML/CSS/JavaScript
